# วิธีติดตั้ง Local Converter บน Windows

Local Converter แปลงคลิป YouTube เป็นไฟล์เพลง MP3 หรือวิดีโอ MP4 เก็บไว้ในเครื่อง
ตัวโปรแกรมรวม yt-dlp และ ffmpeg มาให้แล้ว ไม่ต้องลงอะไรเพิ่ม

**ต้องใช้:** Windows 10 หรือ 11 แบบ 64-bit และอินเทอร์เน็ต

## ติดตั้ง

1. ไปที่หน้า [Releases](https://github.com/Chaiporn2005/yt-converter/releases/latest)
   แล้วกดดาวน์โหลด **LocalConverter-Setup.exe**
2. ถ้าเบราว์เซอร์เตือนว่าไฟล์อาจไม่ปลอดภัย ให้กด **Keep** (เก็บไฟล์ไว้)
3. ดับเบิลคลิกไฟล์ **LocalConverter-Setup.exe**
4. ถ้ามีหน้าต่างสีน้ำเงิน "Windows protected your PC" ขึ้นมา ให้กด **More info** แล้วกด **Run anyway**
   (ที่ขึ้นเตือนเพราะโปรแกรมยังไม่ได้ซื้อใบรับรอง ไม่ได้แปลว่ามีไวรัส)
5. ในหน้าติดตั้ง ถ้าต้องการไอคอนบนเดสก์ท็อป ให้ติ๊ก **Create a desktop shortcut** แล้วกด **Next**
6. กด **Install** แล้วรอจนเสร็จ (ไม่ต้องใช้สิทธิ์ admin)
7. กด **Finish** โปรแกรมจะเปิดขึ้นมาเอง

ครั้งต่อไปให้เปิดจากเมนู Start โดยพิมพ์ **Local Converter** หรือดับเบิลคลิกไอคอนบนเดสก์ท็อป

## วิธีใช้

เมื่อเปิดโปรแกรม จะมี 2 อย่างขึ้นมา:

- **หน้าต่างสีดำ** ข้างในเขียนว่า "Local Converter is running" ต้องเปิดค้างไว้ตลอดที่ใช้งาน
- **หน้าโปรแกรมในเบราว์เซอร์** ที่ `http://127.0.0.1:8765`

ขั้นตอนแปลงไฟล์:

1. วางลิงก์ YouTube ลงในช่อง (หรือพิมพ์ชื่อเพลงเพื่อค้นหา)
2. เลือก **MP3** สำหรับเพลง หรือ **MP4** สำหรับวิดีโอ แล้วเลือกคุณภาพ
3. กด **Convert** แล้วรอจนเสร็จ
4. ไฟล์จะอยู่ในโฟลเดอร์ `Downloads\YT Converter` กด **Show in folder** เพื่อเปิดดูได้

**ปิดโปรแกรม:** ปิดหน้าต่างสีดำ (ปิดแค่แท็บเบราว์เซอร์ โปรแกรมจะยังทำงานอยู่)

## แบบไม่ต้องติดตั้ง (Portable)

ถ้าไม่อยากติดตั้ง ให้ดาวน์โหลด **LocalConverter-Portable.exe** จากหน้า Releases
แล้วดับเบิลคลิกเปิดได้เลย (ถ้ามีคำเตือน ทำตามข้อ 2 และ 4 ด้านบน)
ตัวนี้เปิดช้ากว่าตัวติดตั้งไม่กี่วินาที เพราะต้องแตกไฟล์ทุกครั้งที่เปิด

## ถอนการติดตั้ง

ไปที่ **Settings → Apps → Installed apps** หา **Local Converter** แล้วกด **Uninstall**
ไฟล์เพลงและวิดีโอใน `Downloads\YT Converter` จะไม่ถูกลบ

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| หน้าเบราว์เซอร์ไม่เปิดเอง | เปิดเบราว์เซอร์แล้วพิมพ์ `http://127.0.0.1:8765` |
| ดาวน์โหลดไม่ได้ หรือขึ้น error | ปิดโปรแกรมแล้วเปิดใหม่ ตัวติดตั้งจะอัปเดต yt-dlp ให้เองทุกครั้งที่เปิด ถ้าใช้ตัว Portable ให้โหลดเวอร์ชันใหม่จากหน้า Releases |
| หน้าต่างดำขึ้นแล้วปิดไปทันที | โปรแกรมแอนตี้ไวรัสอาจบล็อกไว้ ให้อนุญาต Local Converter แล้วเปิดใหม่ |
| ใช้ Cut vocal แล้วขึ้นว่าต้องติดตั้งก่อน | ดูหัวข้อด้านล่าง |

## Cut vocal (ตัดเสียงร้อง ไม่บังคับ)

Cut vocal ตัดเสียงร้องออก เหลือแต่ดนตรี ต้องติดตั้ง Python เพิ่มเอง เพราะตัว AI มีขนาดใหญ่มาก

1. ดาวน์โหลด **Python 3.12** จาก [python.org](https://www.python.org/downloads/windows/)
2. ตอนติดตั้ง Python ให้ติ๊ก **Add python.exe to PATH** ก่อนกด Install
3. เปิด **Command Prompt** แล้ววางคำสั่งนี้ จากนั้นกด Enter (ใช้เวลาหลายนาที):

   ```
   pip install demucs==4.0.1 torch==2.5.1 torchaudio==2.5.1 "numpy<2" soundfile==0.13.1
   ```

4. ปิด Local Converter แล้วเปิดใหม่ จากนั้นเลือก **Cut vocal**

ครั้งแรกที่ใช้ โปรแกรมจะดาวน์โหลดโมเดล AI ก่อน แต่ละเพลงอาจใช้เวลาหลายนาที และอาจมีเสียงร้องหลงเหลืออยู่บ้าง
